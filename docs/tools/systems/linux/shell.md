# Shell

## 变量赋值

```shell
abc="123" # 直接赋值，等号左右不要加空格
bcd=$(echo $abc) # 通过执行语句赋值
```

## 文件操作
```shell
current_file_dir=$(realpath $(dirname $0))  # 当前执行脚本所在的文件夹
```

## 管道命令

- 查询日志、切分、排序、统计数量: `cat log.txt | cut -d ' ' -f 10 | sort | uniq -c`
- grep进行正则匹配: -E使用正则， -o 只显示匹配内容
  - 提取数字部分 `grep -o '[0-9]*'`
- tail -f filename 会把 filename 文件里的最尾部的内容显示在屏幕上，并且不断刷新 `tail -f abc.log | grep 'aaa'`
- head 取前几行: `head -n 20`
- 统计行数 `wc -l`


## 命令行工具

| Shell 名称 | 主要特点 | 上手难度 | 适合人群 |
| :--- | :--- | :--- | :--- |
| **Zsh** | **功能全面，社区强大**。拥有强大的补全、主题支持，是 **Oh My Zsh** 框架的基础，可定制性极高。 | 中等（借助框架如Oh My Zsh可快速美化） | **大多数用户**，尤其是希望有丰富主题和插件、寻求“开箱即用”体验的用户。 |
| **Fish** | **用户友好，开箱即用**。语法高亮、智能补全、基于历史的自动建议都默认开启，配置简单。 | **低**（无需复杂配置） | 追求**易用性**、**不想花时间折腾配置**的新手或效率追求者。 |
| **Bash** | **兼容性最强，无处不在**。几乎所有 Unix/Linux 系统的默认 Shell，是编写可移植脚本的**事实标准**。 | 基础使用简单，精通较难 | **系统管理员**、**开发者**（尤其是需要写跨平台脚本时）。 |
| **PowerShell (Core)** | **面向对象，功能强大**。使用管道传递对象而非文本，与 .NET/.NET Core 深度集成，现已成为跨平台工具。 | 中等（需学习新语法） | **系统运维**、**IT专业人员**、需要管理 Windows/Linux 混合环境的用户。 |
