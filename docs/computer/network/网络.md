## 本地路由配置

### MacOs

```bash
# 查看完整路由表
netstat -nr
# 检查特定 IP 的路由
route -n get 192.168.100.11
# 临时路由（重启失效）
sudo route -n add -host 192.168.50.100 192.168.1.254
# 临时添加到子网的路由
sudo route -n add -net 192.168.50.0/24 192.168.1.254
sudo route -n add -net 192.168.50.0/24 -interface ppp0
# 删除临时的路由
sudo route -n delete -host 192.168.50.100
sudo route -n delete -net 192.168.50.0/24
sudo route -n delete default -interface ppp0

# 测试连通性
traceroute 192.168.50.100

```
